# Robinhood Chain ecosystem listing: DoublePlus

## The official directory

- URL: https://robinhood.com/us/en/chain/ecosystem/ ("Discover the ecosystem"; served as /eu/<lang>/crypto/chain/ecosystem/ in the EU)
- It is a curated partner list (about 100 entries: 0x, 1inch, Uniswap, Doppler, Morpho, Alchemy, Blockscout, DefiLlama...). Each card has a name, logo, one-line description, link and a category tag.
- Filter tabs: All, Featured, Trading, Infrastructure, Bridge, Analytics, Wallet, Onramp/Offramp, Lending. There is no Launchpad tab; the closest is Trading.
- There is no public submission form, email or GitHub repo on the page or in the chain docs (https://docs.robinhood.com/chain). The page's only call to action is "Start building", which goes to the docs.
- So the only route is to contact the Robinhood Chain team directly (for example a DM to their X account or through a partner contact) and send the card below.

### Card content, ready to paste

- Name: DoublePlus
- URL: https://doubleplus.fun
- X: @DoublePlusFund (https://x.com/DoublePlusFund)

- One line: Launch a coin on a bonding curve that graduates to a Uniswap v4 pool with locked liquidity.

Holders earn dividends with tiers up to 10x, and from 5x they can be paid in tokenized stocks. Early snipers pay a fee into a buy wall. Limit orders, a last-buyer pot and on-coin chat are built in.
